## Histórico

Registros de auditorias, planos, deploys e diagnósticos que descrevem versões anteriores foram movidos para [archive/2026-09](archive/2026-09/). Eles não devem orientar um novo deploy nem ser usados como fonte do estado atual; servem apenas para consulta histórica.

Não inclua neste diretório capturas de tela geradas, cópias integrais do código, resultados de testes ou scripts de correção pontual. Esses itens não são documentação viva e permanecem no histórico do Git quando necessário.
