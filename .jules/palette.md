## 2023-10-27 - Aria-labels on Login Inputs
**Learning:** In the login form (`apps/web/app/login/page.tsx`), the email and password inputs rely on placeholders for visual context but lack explicit `aria-label` attributes for screen readers. The `LanguageSwitcher.tsx` also lacks `aria-label` on its dropdown options.
**Action:** When adding or reviewing forms or interactive lists, ensure that native input fields and interactive elements without visible, associated `<label>` elements are always provided with explicit `aria-label` attributes (in Portuguese, e.g., 'E-mail corporativo' or 'Mudar idioma para...').
