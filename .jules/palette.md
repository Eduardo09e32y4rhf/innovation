## 2024-07-26 - Password Visibility Toggle Accessibility
**Learning:** In the login page password visibility toggle, removing `tabIndex={-1}` and adding proper `aria-label` along with `focus-visible` styles makes the element keyboard-navigable and understandable for screen readers. Using `focus-visible:ring-inset` on absolute positioned right elements ensures the focus ring doesn't get clipped or appear disconnected from the input field structure. Also, make sure to add `aria-hidden="true"` on inner decorative SVG icons inside buttons with `aria-label` to avoid redundant or weird screen reader announcements.
**Action:** When adding icon-only toggle buttons (like password visibility), always ensure they are keyboard focusable, have `focus-visible` outline styles, use `aria-label` on the button, and apply `aria-hidden="true"` to the inner icons.
