## 2024-03-24 - Interactive Element Focus Rings
**Learning:** Absolutely positioned interactive elements inside input containers (like password visibility toggles) need specific focus ring configurations to look right. If they use default focus rings, they often clip outside the parent container or look misaligned with the container's border radius.
**Action:** When applying Tailwind focus rings (`focus-visible:ring-2`) to such elements, always add `focus-visible:ring-inset` and match the container's border radius (e.g., `rounded-r-xl` if the container is `rounded-xl`) to prevent the focus ring from clipping outside the parent boundary.
