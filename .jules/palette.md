## 2024-08-07 - Add ARIA Labels to Password Toggles
**Learning:** Icon-only buttons used for toggling password visibility in various forms (login, signup, settings) lack ARIA labels and `aria-hidden` attributes on SVG icons, making them inaccessible to screen readers.
**Action:** Always add descriptive `aria-label`s reflecting the current state (e.g., 'Exibir senha' / 'Ocultar senha') to icon-only buttons and set `aria-hidden="true"` on the internal decorative SVG icons. Ensure focus states are accessible (e.g., `focus-visible:outline-none` might need corresponding focus rings if missing, but we're sticking to just aria labels and hidden first).
