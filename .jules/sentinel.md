
## 2026-09-20 - CI Fixes for GitHub Actions and Prisma
**Learning:** CI failures occurred due to forced Node.js 20 on ubuntu-24.04 runners and incorrect type aliasing of `InvoiceStatus` from Prisma. The Node.js 20 deprecation blocked actions like `actions/setup-node@v4` and `actions/checkout@v4` from running successfully when explicitly enforcing `node-version: 20`. Additionally, defining an alias for a Prisma Enum like `type InvoiceStatus = $Enums.InvoiceStatus` immediately followed by `const InvoiceStatus = $Enums.InvoiceStatus` can cause `Cannot read properties of undefined` runtime errors in generated Prisma types if not sequenced properly or due to module loading order in TS compilation for testing. The fix was converting the workflows to Node 24 and ensuring `typeof` or proper ordering was used for the type alias.
**Action:** Update all workflows (`ci.yml`, `ci-cd.yml`, `e2e.yml`) to use `node-version: 24` to stay aligned with the latest runner environments and avoid deprecation failures.
