## 2026-10-03 - Path Traversal Vulnerability in Storage Service
**Vulnerability:** A critical path traversal vulnerability was found in `LocalSupportStorageService` (`apps/api/src/modules/support/local-support-storage.service.ts`). The service directly concatenated a user-provided file key with the base directory using `path.join()`, allowing an attacker to read, write, or delete arbitrary files by using `../` in the key (e.g., `../../../../etc/passwd`).
**Learning:** `path.join()` resolves relative paths but does not restrict the result to the base directory. When user-controlled input is used for file paths, a combination of input sanitization and strict validation using `path.resolve` against the intended base directory is required to prevent traversing out of the directory.
**Prevention:** Always sanitize leading slashes from user-provided file keys (`key.replace(/^\/+/, '')`) and use `path.resolve` to verify that the target path strictly starts with the resolved base directory appended with `path.sep` (or exactly matches the base directory).
