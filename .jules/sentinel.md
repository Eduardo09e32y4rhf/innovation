## 2024-03-24 - Storage Path Traversal Fixed
**Vulnerability:** Found a vulnerability where an attacker could exploit a directory traversal vulnerability by uploading or downloading files with keys like `../../../etc/passwd` because they weren't properly sanitized. This was partially handled in `apps/api/src/modules/jobs/jobs-storage.service.ts` but totally missing in `apps/api/src/modules/support/local-support-storage.service.ts`.
**Learning:** `path.resolve` does not sanitize against absolute paths. If a key starts with `/`, `path.resolve(base, key)` treats the key as an absolute path, effectively ignoring the `base`. Furthermore, without `sanitizedKey.replace(/^\/+/, '')` coupled with the `target.startsWith(resolvedBase)` validation, an attacker could achieve Path Traversal by either providing `../` payloads, or starting strings with `/`.
**Prevention:** Whenever resolving paths constructed partially with user inputs, always strip leading slashes first: `key.replace(/^\/+/, '')` before calling `path.resolve`, and then explicitly check that the resolved path starts with the expected base directory.
